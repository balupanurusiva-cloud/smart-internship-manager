# Smart Internship Manager

This is a Full Stack Web Application developed using Node.js, Express.js, MongoDB, and JavaScript.

## Features

• User Registration  
• User Login using JWT Authentication  
• Create Tasks  
• View Tasks Dashboard  
• MongoDB Database Integration  

## Tech Stack

Frontend: HTML, CSS, JavaScript  
Backend: Node.js, Express.js  
Database: MongoDB
